作者：circlexhy
版本号：0.0.5
本软件可通过伪造极域的UDP数据包来实现对他人的学生端实施控制，可以关闭窗口、发送消息、发送cmd命令、关
机、重启等操作。
本软件仅供学习交流使用，请勿用于非法用途，作者不承担任何责任。
更多信息请访问该项目的github仓库。
使用教程：
   一、管理被控IP地址
      1.添加单个IP：输入被控的IP地址，点击“确定”按钮即可。
      2.添加多个IP：输入IP地址前缀和起始、结束数字，点击“确定”按钮即可批量添加这些IP地址。
      3.删除选中IP：在列表中选中要删除的IP地址，点击“删除”按钮即可。
      4.清空列表：点击“清空”按钮即可清空所有IP地址。
   二、具体功能
      1.关闭窗口：强制关闭被控端最顶上的一个窗口。
      2.发送消息：在文本框中输入要发送的消息，点击“发送”按钮即可将消息以教师端身份发送到被控端。
      3.发送cmd命令：在文本框中输入要执行的cmd命令，点击“发送”按钮即可将命令以教师端身份发送到被控端。
      常用的命令有：
         - shutdown -p：关机
         - shutdown -r -t 0：立即重启
         - taskkill /im 进程名 /f：强制结束指定进程
      可以在自己的cmd上键入help查看更多命令。
      4.修改密码：可以修改他人的极域学生端密码，让其无法进入设置切换频道。
      5.学生端改名（也是重点）：可以修改他人的学生端名称。
      为保证符合改名数据包的格式，请在使用前先阅读下方小技巧
      小技巧：(1)  数据包中有会话 id，会在每次学生端与教师端重新建立连接时重置，教师端每次对某一学生端上发送
改名请求时，该学生端的会话id会加1；
                    (2)  根据(1)可得，教师端与某一学生端建立连接后，第一次对其发送请求时其中的会话id应为01，若想对
该学生端再次发送改名请求，会话id应为02；
                    (3)  由于教师通常不会随便给学生改名，所以给别人改名时可以试填01或02(部分学生端与教师端建立连接
后可能会初始化名称，用掉会话id01)，错了可以反复尝试；
                    (4)  会话id仅针对每一台独立的学生端；
                        (5)  数据包中有教师端用户名，通常为admin，一般无需修改。
